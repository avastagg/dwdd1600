The Code (About)

The Matrix 1999 is a SciFi action movie written and directed by the Wachowskis. It stars Keanu Reeves as the main character, Neo, Laurence Fishburne as Morpheus, and Carrie Anne Moss as Trinity. The movie is set in a dystopian future where humanity is trapped inside a computer simulation created by artificial intelligence.

Key Plot Points

  • The Real World. Set in a ruined future around 2199, machines capable of thought have taken over and currently use human bodies as their energy source.
  • The Simulation. The Matrix is a computer generated world built to mimick the late 90's human life: it was designed to keep people pacified. Almost no one knows they live in a simulation
  • The Awakening. Under the radar computer hacker, Neo, learns the truth about his world from Morpheus. He is extracted from the program and joins a rebel group outside the simulation who fight the machines.
